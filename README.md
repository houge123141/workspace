# 我的 AI 工作台

> 这个仓库是给 AI 用的，也是给人用的。它不是网盘，而是一套带结构的知识管理系统。

## 为什么用 GitHub 而不是网盘？

| 维度 | 网盘 | GitHub + AI |
|------|------|------------|
| 文件夹结构 | 随便建，越存越乱 | AI 帮你维护，永远清晰 |
| 文件关系 | 没有 | 版本历史 + 提交记录 = 知识脉络 |
| AI 读取 | 要上传，格式乱 | 原生支持，大白话就能用 |
| 版本控制 | 没有 | 天然支持，改了什么一目了然 |

## 仓库结构

```
.
├── 公众号/                    # 公众号写作全流程
│   ├── 文章/                  # 发布过的文章（.md 底稿 + .html 排版稿 + 配图）
│   ├── 素材/                  # 写作素材、参考文章、灵感片段
│   ├── 脚本/                  # 生图脚本等自动化工具
│   └── 档案/                  # 风格档案、写作规范、发布流程
│
├── 英语辅导/                  # 小学英语自然拼读相关
│   ├── 自然拼读/              # 元音发音表、拼读规则
│   ├── STORYFUN/              # STORYFUN 教辅资料、课文笔记
│   └── 教材封面/              # 书籍封面图（引用用）
│
├── 学习资料/                  # 其他学习资料
│   └── 小学/                  # 小学各科资料
│
└── 工具/                      # 配置、脚本、自动化
    ├── 脚本/                  # 各种实用脚本（生图、数据处理等）
    ├── 配置/                  # opencode 配置、风格档案等
    └── 密钥/                  # API 密钥（已 gitignore，不会上传）
```

## 使用说明

### 对 AI（比如 OpenCode）

直接读取仓库中的文件即可。AI 天生理解 GitHub 的文件结构和 README，不需要额外解释。

```
# AI 可以这样读取
读取 公众号/风格档案.md
读取 英语辅导/自然拼读/元音发音总结表.md
```

### 对人

1. 把这个仓库克隆到本地
2. 直接打开文件夹，按目录结构存放资料
3. 需要 AI 帮忙时，告诉 AI 仓库路径，它会自动理解结构

## AI 自动化工作流

```
你说想法 → AI 读取风格档案 → 生成初稿 → 存入公众号/文章/
                                                    ↓
                                              公众号/文章/images/（自动配图）
                                                    ↓
                                              公众号/文章/（HTML 排版）
```

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/houge123141/workspace.git

# 进入目录
cd workspace

# 开始使用
```

## 注意事项

- `工具/密钥/` 目录已设置 gitignore，**不会被上传到 GitHub**
- API 密钥等敏感信息只存本地
- 所有文章的 `.md` 和 `.html` 文件都保留，方便后续修改
