# 公众号写作

## 文件夹说明

| 文件夹 | 内容 |
|--------|------|
| `文章/` | 已发布的文章（.md 底稿 + .html 排版稿 + images/ 配图） |
| `素材/` | 写作素材、参考文章、灵感片段 |
| `脚本/` | 生图脚本等自动化工具（agnes_gen.py 等） |
| `档案/` | 风格档案.md（写稿前必读）、写作规范 |

## 工作流程

```
你说想法 → 读取档案/风格档案.md → 出初稿 → 存入文章/YYYY-MM-DD-标题.md + .html
```

## 重要文件

- `档案/风格档案.md` - 写作规范和语气基准
- `脚本/agnes_gen.py` - AGNES 免费生图脚本
- `.secrets/agnes_api_key.txt` - AGNES API 密钥（不上传）
